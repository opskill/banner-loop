Sample headline

Seamless loops,
made from code

The centre stays dark and calm so your HTML headline reads on every frame.

Every clip below is a 5-second, 150-frame loop that never shows a seam: Blender scene scripts rendered with Cycles at 1920×540, then upscaled to 3840×1080 with Apple's on-device super-resolution. No stock footage, no text or logos in the video — only procedural geometry and two CC0 textures.

Why render 1920 and upscale

7–23 s / frameCycles at 1920×540 on an M2 Pro (17–57 min per loop)
≈ 5 min 20 sAI 4× upscale per loop, independent of scene complexity
~3–3.5× fasterthan rendering 3840×1080 directly (≈ 4× the pixels to path-trace)

Use it

As a Claude Code plugin — then just ask “render the cable trays loop in 4K”:

claude plugin marketplace add opskill/banner-loop
claude plugin install banner-loop@banner-loop

Or from a clone (macOS 26+ for the 4K step, Blender 5.x, Node 20+, ffmpeg):

git clone https://github.com/opskill/banner-loop && cd banner-loop
npm run assets
tools/loop.sh --scene concept_cable_trays --key 10_cable_trays
